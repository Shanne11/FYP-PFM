# Final protocol and deviations

1. Participant-disjoint splits were retained for seeds 42, 52, 62, 72 and 82.
2. Strict description-template disjointness was infeasible because repeated templates link participants into one connected component. Template overlap and a frozen-prediction sensitivity are therefore reported; no alternative model was trained.
3. B1 and B2 use the same frozen unified classifier and preprocessing within each seed; only the optional Smart Note input differs.
4. All 254 notes were marked answered. Response time is unavailable.
5. Reference labels are owner-confirmed rather than independently adjudicated.
6. Stage C is offline pre-collected-note replay, not live ACTM prompting.
7. Learned Benefit and G3 were not evaluated because grouped out-of-fold isolation was infeasible.
8. Housing and Insurance remain in the 14-category universe with zero observed support.
